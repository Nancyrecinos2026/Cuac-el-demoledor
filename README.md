# JuegoPC 
CUAC EL DEMOLEDOR es un juego de estrategia por turnos en el que debes defender una fortaleza de diferentes enemigos. En cada turno puedes colocar bloques, reparar la base o comprar poderes. Después, un enemigo ataca y debes evitar que la princesa o la base reciban daño. Si sobrevives y derrotas al enemigo, ganas el nivel. Video Juego en Python

Instrucciones:
Ejecuta el juego en Python.
Presiona ENTER para comenzar.
Elige una opción escribiendo su número.
Responde si/no cuando se indique.
Protege la base y derrota al enemigo para ganar.

# 1.Analisis 
Cuac el Demoledor es un juego de estrategia por turnos donde debes proteger a la princesa Mia construyendo y reparando una fortaleza contra patos y animales enemigos.
Cómo juegas: En tu turno colocas bloques o usas poderes; luego, los enemigos atacan.
Enemigos: Patos que destruyen bloques, un mapache que roba y un topo que ataca por abajo.
Ganas: Si pasas todos los niveles y salvas a Mia.
Pierdes: Si Mia se lastima, la fortaleza cae o te quedas sin bloques.
